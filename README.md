
# CodeAlpha Hangman Game

## Project Description
Hangman is a simple text-based word guessing game developed using Python.

The computer randomly selects a word from a predefined list of five words. The player must guess the hidden word one letter at a time.

## Features
- Random word selection.
- Five predefined words.
- Maximum six incorrect guesses.
- Letter-by-letter guessing.
- Input validation.
- Win and Game Over messages.
- Play Again option.

## Technologies Used
- Python
- Random Module
- Loops
- Conditional Statements
- Lists
- Functions

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python hangman.py
```
